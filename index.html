Rules this planner applies

Cover

  • Cover teacher must teach the same class at some point in the week — the weekday doesn't matter, they are stepping in. Teachers who already have that class on the day itself rank lower, so a cover doesn't create a double or triple of one class
  • Their slot must be free or CP
  • Must still have ≥ 3 free/CP periods after covering
  • Daily lesson cap: max 4 lessons Mon/Tue/Thu · max 6 Wed/Fri (Study Hall, Reading and Homeroom don't count)
  • One cover per teacher per sick day (shared across all sick teachers)
  • PE teachers never cover — read from the uploaded Teaching Roster, or TZC/TUW/CJYJ/TCY if none uploaded
  • VA teachers used only as last resort — read from the uploaded Teaching Roster, or FSM/WWS/PMY/KPY if none uploaded
  • Same campus only: a cover teacher must be at the lesson's campus that day, and a return is only placed where the sick teacher is at the cover's campus that day. Read from the uploaded Cross Campus Teachers file (a split day like "MK/DH" = not used that day); without it, campus presence is inferred from the timetables
  • Ranked by fewest teaching lessons; slots with fewest options assigned first

Reading & Study Hall

  • Reading 8:35–8:55 · none on Friday (assembly)
  • Study Hall = L7 Mon/Tue/Thu, L9 Wed/Fri
  • P1 same class → P2 any free teacher with that duty on another day. For Study Hall, a teacher whose own Study Hall is with the same class comes first, so the swap gives back the same class
  • Study Hall blocked: Tue English · Wed Chinese · Thu Maths
  • Make-up days follow the named weekday's timetable for the lesson range given in the calendar (e.g. "Make-up Monday timetable … (L1-L6)")

CP fallback & return swaps

  • Last resort: a teacher with CP in that period covers, even off-class. Also used when the only same-class teacher is already covering another of the sick teacher's lessons (e.g. a Chinese double lesson) — that slot falls back to CP rather than being left uncovered
  • Return = same slot type, a later date (next week's same weekday counts), sick teacher free/CP, ≥ 3 free left. The same class that was covered is strongly preferred; if it has no valid slot, any class the sick teacher teaches that week is taken rather than losing the return
  • Returns are placed on the earliest date the rules allow — every day of delay counts against a slot, so a valid Wednesday beats an equally valid Monday the following week
  • Returns aim to fall within 2 weeks (tagged LATE RETURN after that) and stay within 3 weeks — beyond that only to avoid a Goodwill cover
  • At most one lesson return per day per sick teacher (per date — two different Mondays are two days). Study Hall and Reading returns don't use up a day, so they can share one
  • A return must not give the sick teacher 3+ lessons of the same class in one day — this outranks the 2-week target
  • All of a sick teacher's returns are chosen together (lowest total penalty), not one slot at a time
  • Every row is editable: the Substitute Teacher and Swap Date cells are dropdowns. Each option shows the day it would create — lessons now → after, against that day's cap, and how many of that class it would make — and the option the app itself chose is marked ★ app's pick. Changing the cover re-picks the earliest valid return automatically; a clash with another row (same teacher covering twice, two lesson returns on one date) is flagged in the Remark column but never blocked
  • A Study Hall return prefers the same class that was covered; failing that, any of the cover teacher's Study Halls — it's supervision
  • The Swap Date dropdown lists every valid lesson, including a second lesson on the same day (e.g. Wed/Fri L7 and L8)
  • Returns respect the same daily lesson cap (4 Mon/Tue/Thu · 6 Wed/Fri)
  • Days with a double (back-to-back) lesson avoided for returns where possible
  • CP remark applies to whoever uses a CP slot — cover teacher or sick teacher
  • No valid return → Goodwill cover
